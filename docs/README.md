# 微光机 ViewPhone · 文档总索引

> 这是**实施入口**。项目根目录 `D:\deepseek\viewphone`。**不迁移前身任何数据，不兼容任何旧格式。**
> 一句话：**一台装满了 AI 角色的平行手机**——Android 原生 App 为主端，Web/PWA 为次端（用于覆盖 iOS 用户）。
> 前身项目「叙事诗小手机」只用于**查玩法**，不迁数据、不抄实现（查证入口见 `01-PRODUCT-AND-STACK.md` §〇）。

## 一、怎么用这份文档（新窗口第一步）

1. **先读 `00-CONSTITUTION.md`**（项目宪法，最高权威）。它的 §六「永久禁止清单」每写一段代码都要对照。
2. 再读 `01`（做什么）→ `02`（代码放哪）→ `04`（怎么排期、怎么验收）。
3. 然后按 `04-ROADMAP.md` §七 的**启动指令**开工：P0 阶段先把仓库与 CI 立起来。
4. 领域细节在**对应阶段开工前**再读（见下表"何时读"）。

**工作方式**：每完成一个模块，输出变更文件清单 + 关键决策 + 测试命令与**真实输出**；遇到架构歧义给 2~3 个方案对比再让人决策；**门槛未过不许进入下一阶段**。

## 三、三条不可妥协的体验（验收判据）

| # | 体验 | 判据 |
| :--- | :--- | :--- |
| **E1** | **长周期记忆**：三个月前说过的话，今天能被自然提起 | 注入 300 轮历史后问"我上次说的那个事"，角色能答对，且 Trace 里能看到召回的那段原文 |
| **E2** | **后台活着**：关掉 App 后仍能收到角色的主动消息并自动回应 | 真机锁屏 30 分钟，至少收到并自动回一条 |
| **E3** | **永远不卡不崩**：十万条消息、整本小说导入、上千张图片 | 见下方四道红线 |
