# 第 1 轮 · 装机自测清单

> 目标：装上 debug APK，走一遍「进桌面 → 进设置 → 进角色库」，确认外壳能开。
> 本轮**还没有** API 配置与角色库的界面代码（设计稿待你认可后才写，见 DEC-017），
> 所以第 ②③④ 步现在只能看到入口，点了会提示「开发中」。

## 前置

- 一台 Android 手机（Android 8.0 / API 26 及以上），或模拟器
- 允许「安装未知来源应用」
- APK 来源：GitHub Actions 的 `viewphone-debug-apk` 产物（**保留 1 天**，过期需重跑工作流）

## 安装

1. 手机上下载或从电脑传过去那个 `.apk`
2. 点击安装；如提示风险，选择「仍要安装」
3. 桌面会出现 **微光机** 图标（就是你给的那张图）

## 自测 8 步

| # | 操作 | 预期 |
| :-- | :--- | :--- |
| ① | 点图标打开 | 直接进入桌面：状态栏（9:41 / 100%）、大时钟、日期、天气、8 个应用图标、底部 Dock |
| ② | 看未读与灰显 | 「聊天」右上角有红色数字点；「相册」等未实现应用**灰显** |
| ③ | 点一个灰显应用（如「相册」） | 提示「相册 · 开发中」，**不进入假界面** |
| ④ | 点 Dock 里的「设置」 | 进入设置页，看到分组：模型与接口 / 数据 / 调试 |
| ⑤ | 点「API 配置」 | 目前**还未实现**（设计待认可）——若点了没反应，属预期，请报告 |
| ⑥ | 返回桌面（左上角 ‹） | 回到桌面，状态保持 |
| ⑦ | 关掉 App 再打开 | 能正常重开，仍在桌面 |
| ⑧ | 报告任何不对 | 截图 + 你做了什么 + 看到什么 |
