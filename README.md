# 微光机 ViewPhone

> 一台**装满了 AI 角色的平行手机**：主端是 Android 原生 App，次端是 Web / PWA（使命是覆盖 iOS 用户）。
> 核心（占 60% 以上工程量）是与角色的**高质量长周期对话**；其余应用是围绕核心的「世界感增强层」。

## 二、三条不可妥协的体验

| # | 体验 | 可执行判据 |
| :--- | :--- | :--- |
| **E1** | 长周期记忆：三个月前说过的话今天能被自然提起 | 注入 300 轮历史后问「我上次说的那个事」，角色答对，且 Trace 里能看到召回原文 |
| **E2** | 后台活着：关掉 App 后仍能收到角色主动消息并自动回应 | 真机锁屏 30 分钟，至少收到并自动回 1 条 |
| **E3** | 永远不卡不崩：十万条消息、整本小说导入、上千张图片 | 四道测试红线全部常绿 |

## 三、四道测试红线（红了不许合并）

1. **提示词 golden**：20 组 `ContextBundle` 的编译产物与旧版 oracle 逐字节一致（含线下 `-50/-40/-30` 段）。
2. **写入守卫**：`data:` / base64 传给**生产仓储**必须抛错，且 `COUNT(*)` 前后不变。
3. **全表备份覆盖**：反射枚举实体表 ↔ `BackupRegistry` 双向比对，差集非空即失败。
4. **十万条分页性能**：第 1 页与第 1000 页 P95 < 50ms，`EXPLAIN` 必须出现 `SEARCH ... USING INDEX`。

## 四、工作规则（宪法 §七）

1. 每完成一个模块，输出：**变更文件清单 + 关键设计决策 + 测试命令与真实输出**（不许编造结果）。
2. 遇到架构歧义：给 2~3 个方案对比（含取舍）由人决策，**不擅自选择**。
3. 不确定就说不确定；**没验证过的不许声称已验证**。
4. 代码注释与文档用**中文**；变量名 / API 用**英文**。
5. 每个阶段结束跑对应验收清单，**未过不许进入下一阶段**。
6. 想绕过宪法条款的「临时变通」，先问，不许自己放行。

## 五、本仓库工程约定

| 项 | 约定 |
| :--- | :--- |
| 依赖版本唯一来源 | `gradle/libs.versions.toml`，**禁浮动版本** |
| 行尾 | 统一 LF（见 `.gitattributes`），二进制类型显式声明 |
| 密钥 | 一律环境变量 / CI Secret / Keystore；`.gitignore` 已覆盖 `*.jks` / `*.keystore` / `local.properties` |
| 机器相关配置 | 不进仓库（例如 JDK 路径写在本机 `%USERPROFILE%\.gradle\gradle.properties`） |
| 提交信息 | 中文，按 `feat:` / `fix:` / `refactor:` / `docs:` / `test:` / `chore:` 分组 |
